# Appendix B — Support

If you run into an issue this guide doesn't resolve, or need help at any
stage of onboarding or day-to-day use, reach out to the LinkEye CS team.

| Contact | csteam@linkeye.team |
|---|---|
| What to include | Customer/tenant name, affected site or device, the module you were in, and a screenshot of the RCA Summary or error state if available. |
| Response | The CS team will validate your setup or issue and provide the guidance needed to resolve it. |
