# Appendix A — Glossary

Terms used throughout this guide.

**API**
Application Programming Interface — one of the credential types used to
monitor devices and services.

**Compliance Agent**
The AI agent tracking hardware end-of-life/support risk and software
vulnerabilities.

**Co-Pilot Insights**
The panel showing passed/failed tests, root cause, and plan of action for
a specific link or application incident.

**CVE**
Common Vulnerabilities and Exposures — the industry ID for a known
software vulnerability, shown in Vulnerability Details.

**Data Collector**
A distributed agent deployed on your infrastructure that ingests
telemetry via SNMP/API and forwards it to LinkEye.

**Digital Experience (DX)**
The domain covering end-to-end application performance from a site
through the ISP to the cloud application.

**EOL**
End of Life — the date a device is no longer supported or updated by its
vendor at all.

**EOS**
End of Support — the date a vendor stops providing standard support for a
device.

**ILL**
Internet Leased Line — a dedicated, symmetric internet circuit type.

**LAN**
Local Area Network — internal subnets and devices at a single site.

**MPLS**
Multiprotocol Label Switching — a private, carrier-managed WAN link type.

**MTTR**
Mean Time to Resolution/Repair — the average time to resolve an incident.

**Multi-homed Site**
A site with more than one active WAN path, providing redundancy.

**RCA**
Root Cause Analysis — the AI-generated statement of the most likely
source of a fault.

**RCA Agent**
The AI agent diagnosing connectivity and application issues across
Internet and Applications views.

**Single-homed Site**
A site with exactly one active WAN path and no redundancy.

**SLA**
Service Level Agreement — the contractual performance commitment
(uptime, TTR) tracked against a vendor.

**SNMP**
Simple Network Management Protocol — used to poll device metrics and
status.

**SSH**
Secure Shell — used for credentialed device access, e.g. config backup.

**TTR**
Time to Resolution — a vendor's promised or actual repair time, tracked
on the Vendor Details page.

**WAN**
Wide Area Network — the external links connecting a site to the internet
or other sites.

**WAN Economics**
The CIO Insights module quantifying penalty cost and loss by vendor and
location.
