# 5. Reports

Reports turns operational data into shareable documents — pre-built for
common categories, or fully custom for recurring stakeholder needs.

## Ready Reports

Choose a category, set the controls, and the table and download update
together.

| Element | Options |
|---|---|
| Report Categories | Links, Vendors, Sites, Devices |
| Controls | Business Hours vs. 24×7, Month & Year selection |
| Table | Columns change automatically per category; data updates with the selected filters |

## Custom Reports

Build a template once and reuse it. Saved templates appear in a list with
per-template actions: **Download, Regenerate, Edit,** and **Delete.**

---

**Q. How do I export a report for a client review?**

1. Go to Reports → Ready Reports (for a standard category) or Reports → Custom (for a saved template).
2. Set the category or open the template, then choose Business Hours or 24×7 and the reporting month/year.
3. Review the table — this is exactly what will be exported.
4. Select **Download Report**. For a Custom template you can also select **Regenerate** first if the underlying data has changed since the template was last run.
