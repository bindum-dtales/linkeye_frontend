# 3.1.2 RCA Agent — Applications

The Applications view applies the same model to business-critical apps
rather than links.

| Counter | Meaning |
|---|---|
| Total Apps | All monitored applications |
| Down Apps | Apps with no successful path |
| Poor Apps | Apps with degraded performance |
| Partially Good Apps | Apps healthy for some sites or paths but not all |

App Entries carry the same RCA Summary pattern as the Internet view,
scoped to the application's delivery path rather than a single link.
