# 15. Sites

Sites is where you define the organizational structure that Overview,
Topology, and every filter panel in the platform draws from.

| Structure | Actions available |
|---|---|
| Business Units | Add Business Unit; Map Business Unit → Location |
| Zones | Add Zone; Map Zone → Location |
| Groups | Add Group; Map Group → Location |

> **Why This Matters**
>
> Every filter you use elsewhere in the platform — Zone/Site Group on
> Overview, the four Topology views, CIO Insights breakdowns — reads from
> these mappings. Set them up deliberately before onboarding a large
> batch of sites.
