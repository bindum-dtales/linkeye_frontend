# 18.2 LAN-Only Onboarding

Onboards local networks, subnets, and internal LAN devices.

## Step 1: Add Locations and Subnets

**Bulk method**

1. Go to Settings → Onboarding → Assets Manager.
2. Click **Upload Multiple Locations** (3rd tab).
3. Download the Sample XLSX, fill in location and subnet details, and
   upload.

**Manual method**

1. Go to Settings → Onboarding → Site Management.
2. Click **Add Location** and select **LAN**.
3. Enter location details and add your subnet, then Save.

## Step 2: Add Network Credentials

Once added, credentials map automatically to your subnets.

**Bulk method**

1. Go to Settings → Onboarding → Assets Manager.
2. Click **Upload Multiple Credentials** (4th tab).
3. Download the Sample XLSX, enter SNMP/SSH details, and upload.

**Manual method**

1. Go to Settings → Onboarding → Network Credentials.
2. Choose the tab for your device type:
    - **SNMP:** Add Credentials, select v2 or v3, enter Auth Details, Save.
    - **SSH:** Add Credentials, enter Username, Password, Port, Save.
    - **API:** Add API Endpoint, enter Token, URL, Port, Save.
