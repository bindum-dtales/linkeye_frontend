# 14. Site DX Apps

Defines which business-critical applications Digital Experience
Monitoring tracks.

## Add New Application

Use the Add New Application form to register an Internal or SaaS
application for DX monitoring. Once added, it appears in the
Applications list on the Site-Level Digital Experience Dashboard
(see [Part I, Chapter 4](../part-i-home/04-digital-experience.md)) for
every relevant site.
