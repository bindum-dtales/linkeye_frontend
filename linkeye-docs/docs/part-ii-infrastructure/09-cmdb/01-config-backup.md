# 9.1 Config Backup

Two dashboards summarize the state of your backup coverage:

| Dashboard | Shows |
|---|---|
| CMDB Inventory Overview | Total inventory and scannable items, visually represented |
| CMDB Scan Status | Scan success %, total scans, failed scans, visually represented |

The Config Backup table lists every entry with its backup folder
(downloadable config files) and, where applicable, the reason a backup
didn't complete. Use **Pause Scan** on a device to exclude it temporarily.
