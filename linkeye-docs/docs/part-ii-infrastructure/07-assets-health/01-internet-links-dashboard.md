# 7.1 Internet — Links Dashboard

A dashboard counts **Total, Good, Down, Poor, Flapping, Paused,** and
**Not Monitored** links. Click any counter to open the Links table
filtered to that state, with columns for link name, type, and status.
Select View on any row to open its Link-Specific Dashboard.

A Troubleshooting section lists completed tests, failed tests, Root Cause
Analysis, and Plan of Action for the link.

## Special Cases

- **Down links:** the table carries an Insights button opening RCA, Plan
  of Action, and failed-test detail directly.
- **Poor links:** a summary is available inline, and the full
  link-specific dashboard remains one click away via View.
