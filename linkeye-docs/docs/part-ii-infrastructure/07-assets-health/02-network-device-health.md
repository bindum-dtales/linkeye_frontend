# 7.2 Network — Device Health

Two summary graphs — Devices by Vendor and Devices by Type — sit above the
Devices table. Clicking a segment in either graph auto-filters the table.

Per device, the available actions are:

| Action | What it opens |
|---|---|
| Device Health | Name, version, model, uptime, serial number, and related identity fields |
| Utilization | CPU usage and memory usage |
| Availability | Up/down history for the device |
| Interfaces | Per-interface status |
| MAC Table | Learned MAC addresses on the device |
| Pause Scan | Temporarily excludes the device from active scanning |
| Mark / Delete as Edge Device | Reclassifies the device into or out of the Edge Devices set below |
