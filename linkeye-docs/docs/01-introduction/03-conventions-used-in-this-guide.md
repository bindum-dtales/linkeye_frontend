# Conventions Used in This Guide

| Convention | Meaning |
|---|---|
| Settings → Users | A navigation path. Follow each arrow-separated item in order from the left navigation panel. |
| Numbered steps | A procedure to complete in the product, in order. |
| Note / Warning boxes | Supplementary guidance, prerequisites, or things to double-check before proceeding. |
| Q. / Answer | A frequently asked "how do I…" question, answered in place within the relevant chapter. |
