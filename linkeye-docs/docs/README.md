# Agentic AI NetOps Platform — User Guide

A complete reference for navigating LinkEye.

LinkEye Product Documentation · 2026 Edition

This guide explains how to use each module in the platform, how it connects
to the rest of the platform, and how to perform the tasks NOC engineers,
network managers, and CIO stakeholders rely on most.

See [SUMMARY.md](SUMMARY.md) for the full table of contents.

## Parts

- **Part I — Home**: the day-to-day working surface. Global observability,
  AI-driven root cause and compliance agents, digital experience, reporting,
  and executive insights.
- **Part II — Infrastructure**: the asset layer beneath Home — device and
  link health, network topology, configuration history, inventory records,
  and the full event log.
- **Part III — Settings**: administrative control — users and access,
  applications, site structure, WAN management, alerting, and onboarding.
